## 🚀 Getting Started
1. Clone the repository
git clone https://github.com/Abhinav1574k/abhinav-portfolio.git

2. Navigate to the project
cd abhinav-portfolio

3. Install dependencies
npm install

4. Start the development server
npm run dev

5. The application will normally be available at:
http://localhost:5173


## 🏗️ Production Build
1. Create a production build with:
npm run build

2. Preview the production build locally:
npm run preview


## 🧩 Adding a New Project
1. Projects are stored separately from the UI in:
src/data/projects.js

2. A project follows a structure similar to:
{
  id: "project-id",
  number: "04",
  title: "Project Name",
  subtitle: "Project Subtitle",
  category: "FULL STACK",
  description: "Project description.",
  problem: "Problem being addressed.",
  solution: "Approach used to address the problem.",
  role: "Full-stack development",
  technologies: [
    "React",
    "Node.js",
    "MongoDB"
  ],
  status: "COMPLETED",
  featured: true,
  image: null,
  github: "",
  live: "",
  future: false
}

- This makes the portfolio easier to maintain and expand.
